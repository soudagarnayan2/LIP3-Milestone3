# Google Stitch Prompt — SBI Mutual Fund RAG Chatbot (Dark Theme UI)

Paste the following prompt into Google Stitch:

---

Design a premium, dark-themed AI chatbot web interface for "SBI Mutual Fund FAQ Assistant" — a Retrieval-Augmented Generation (RAG) chatbot that answers investor questions about mutual fund products.

## Design Requirements:

**Overall Theme:**
- Dark mode with a deep navy/slate background (#0f172a to #1e1b4b gradient)
- Glassmorphism cards with frosted blur and subtle white borders (rgba(255,255,255,0.08))
- Accent colors: Electric Blue (#3b82f6) for primary actions, Cyan (#06b6d4) for highlights and citations
- Typography: Inter or similar clean sans-serif font

**Header Bar:**
- Left: SBI logo icon (gradient blue-to-cyan rounded square with "S" letter) + App title "SBI Mutual Fund Assistant" with a small subtitle "Powered by RAG · Groq LLM"
- Right: Language toggle pill (EN | हि) and a green pulsing "online" dot
- The header should be a glassmorphism card with a subtle blue glow shadow

**Chat Area (Center):**
- Empty state: Large centered chat icon, welcome heading "Welcome to SBI MF Assistant", subtitle explaining what the bot can do, and 4 starter suggestion chips in glassmorphism pills (e.g., "What is SBI Gold Fund?", "NAV of SBI PSU Fund?", "Tell me about SBI Contra Fund's risk", "Compare SBI Large Cap and Pharma Fund")
- User messages: Right-aligned bubbles with a blue gradient background (#1a56db to #3b82f6), rounded corners (16px top, 4px bottom-right)
- Bot messages: Left-aligned bubbles with a dark glassmorphism background, subtle border, rounded corners (16px top, 4px bottom-left)
- Citation chips: Below bot messages, small cyan-bordered pills with a link icon and "Source" text that link to Groww.in
- Typing indicator: Three bouncing dots animation inside a bot message bubble
- Smooth slide-up animation for new messages appearing

**Input Area (Bottom):**
- Full-width glassmorphism card with blue glow
- Text input with placeholder "Ask about SBI Mutual Funds..."
- Send button: Blue gradient with a paper-plane icon and "Send" text
- Tiny disclaimer below: "Responses are grounded in official SBI MF data. Not financial advice."

**Visual Effects:**
- Subtle glow effects (box-shadow) on the header and input area
- Smooth fade-in and slide-up animations for messages
- Gradient text effect on the app title (blue to cyan)
- Custom thin scrollbar matching the dark theme
- Hover effects on all interactive elements (scale, border color change)

**Responsive:**
- Mobile-first design, works beautifully on both phone and desktop
- Chat area fills available height between header and input

**Do NOT include:**
- No sidebar or navigation menu
- No device frames (laptop/phone mockups)
- No login/signup screens
- Just the chat interface itself
